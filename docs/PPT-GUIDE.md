# PPT 制作指导书（供 AI Agent 执行）

> 目标产物：**22 页学术风格汇报 PPT**，主题「藏语 OCR / ASR 开源模型本地化评测」。
> 本文件写给负责生成 PPT 的 agent。请**严格按 §1 的设计规范**和 **§3 的逐页细则**执行，不要自由发挥排版与配图风格。
> 内容依据：[PROJECT-SUMMARY.md](./PROJECT-SUMMARY.md)；所有数字必须与本文件一致，**禁止编造新数字**。

## 0. 交付要求（先读这一段）

1. **页数**：22 页，不多不少。
2. **比例**：16:9（13.333 × 7.5 in / 33.87 × 19.05 cm）。
3. **语言**：中文为主；专业术语首次出现给英文全称，例如「字符错误率（Character Error Rate, CER）」。
4. **图**：**全部留占位框**，不要生成图片、不要用 emoji、不要用装饰插画。占位框内写清楚「图 X：内容 + 尺寸」，并在框内用浅灰小字标注拍摄/制作说明。用户会自己截图贴入。
5. **表**：表格必须真实可读，用 §4 的表格样式。
6. **禁止**：彩色渐变、圆角卡片、阴影、3D、图标堆砌、动画切换、每页不同主题色、大段文字（单页正文 ≤ 120 字）。
7. **每页必须有**：页眉（右侧小节名）、页脚（左侧「藏语 OCR / ASR 评测」+ 右侧页码）。
8. **输出**：同时给出 **演讲备注（speaker notes）**，内容见每页「讲述要点」。

### 第 14 页 · 发现二：Whisper 的 448 token 上限

**版面**：双栏，左图（折线），右文字。

**图（左栏）**
