## 0. 交付要求（先读这一段）

1. **页数：12 页，不多不少。** 每页信息密度高、版面填满（目标版面利用率 80–90%），**不要留大片空白**。
2. **比例**：16:9（13.333 × 7.5 in / 33.87 × 19.05 cm）。
3. **不要做的事**：
   - ❌ 不要目录页、不要"谢谢观看"页、不要过渡页/章节封面页
   - ❌ 不要彩色渐变、圆角卡片、阴影、3D、图标堆砌、emoji、动画切换
   - ❌ 不要每页不同主题色
   - ❌ 不要生成图片：图**全部留虚线占位框**（数据类图表除外，见 §4）
4. **语言**：中文为主；术语首次出现给英文，如「字符错误率（Character Error Rate, CER）」。
5. **每页必须有**：页眉（右侧小节名）、页脚（左「藏语 OCR / ASR 评测」+ 右页码 `n / 12`）。
6. **每页必须附演讲备注**（speaker notes），内容见每页「讲述要点」。

## 1. 设计规范（唯一标准，全篇一致）

### 1.1 配色（只用这 6 个色）

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#FFFFFF` | 纯白 |
| 主文字 | `#1F2328` | 近黑，不用纯黑 |
| 次要文字 / 页眉页脚 / 注释 | `#6E7781` | 中灰 |
| 分隔线 / 表格线 / 占位框 | `#D8DEE4` | 浅灰，1 pt |
| **强调色**（标题线、关键数字、图表主色） | `#0B4F6C` | 深青蓝 |
| **警示色**（仅"错误/失败/风险"） | `#A40E26` | 暗红，全篇**仅 5 处**（见下注），不得用于装饰 |

> 层次用同一色的透明度区分（`#0B4F6C` 的 25% / 50% / 75%），不算新增颜色。
> 唯一允许的浅底：表头 `#F6F8FA`。
>
> **暗红 `#A40E26` 的 5 个允许位置**：① 第 4 页图 2 的「打字机」条形；② 第 6 页图 3 的「儿童语音」条形；③ 第 8 页工作点要求框边框；④ 第 9 页警示框边框；⑤ 第 9 页表 10 中 ≥95% 的三个数值文字。其余任何地方都不得使用红色。

| 小节标签（标题上方，英文全大写） | 思源黑体 | 11 pt | Medium，字间距 +0.08em，`#6E7781` |

### 1.3 版面网格

```
┌────────────────────────────────────────────────────┐
│ 页眉：左 小节编号+名称             右 当前小节      │ ← 距顶 0.3in，9pt，#6E7781
│                                                    │
│  ┌─ 标题 26pt                                     │ ← 距顶 0.62in
│  └─ 横线 2pt #0B4F6C，长 1.4in                    │
│                                                    │
│   正文区（距顶 1.35in，左右边距 0.7in）             │ ← 高 5.6in
│   按每页给定的分区图摆放，不留大块空白              │
│                                                    │
│ 页脚：藏语 OCR / ASR 评测                  3 / 12  │ ← 距底 0.28in
└────────────────────────────────────────────────────┘
```

- 左右边距 **0.7 in**；正文区 **11.93 × 5.6 in**。
- 模块之间最小间距 **0.18 in**；模块内部文字贴边不留空。
- 每页 **3–5 个模块**（表 / 图 / 文字块 / 结论带），**必须至少一个表或图占 ≥40% 宽度**。

### 1.4 表格样式

- **无竖线**；表头上下 1 pt、行间 0.5 pt `#D8DEE4`；表头底纹 `#F6F8FA`。
- 数字列**右对齐**、模型名列左对齐；表内数字全部等宽字体。
- 最优值：**加粗 + `#0B4F6C`**（不用底纹色块）。
- 异常值（如 ≥95%）：红色文字 `#A40E26`，不加粗。
- 表格行高压缩到刚好容下 13 pt 文字（约 0.28 in/行），以便单页放两张表。

### 1.5 图占位框规范

虚线矩形（1 pt 虚线 `#D8DEE4`，无填充、直角），框内两行居中文字（11 pt `#6E7781`）：

```
图 6 ｜ 评测界面：原图 + 指标卡 + 逐字差异
[ 7.0 × 3.6 in ｜ 需用户截图，见 §5-F6 ]
```

**不要在占位框里画假图。**

### 1.6 结论带（本 PPT 的核心排版手法）

每页底部放一条横跨全宽的「结论带」，用于一句话结论：

- 高度 0.5 in，**无填充**，上边一条 1.5 pt `#0B4F6C` 粗线（替代色块）。
- 文字 17 pt、加粗、`#1F2328`，左侧缩进 0.1 in。
- 第 2–11 页共 10 页用它收尾（第 12 页底部为参考条），形成统一视觉节奏。
